# Arquitectura: Semáforo Financiero AI Evolution

## 🎯 Visión
Transformar una herramienta de registro local-first en un asesor financiero inteligente para microempresas informales, capaz de entender lenguaje natural complejo y sugerir acciones estratégicas.

## 🗺️ Roadmap de Implementación

### Sprint 1: Cerebro Semántico (AI Parser)
- **Estado:** 🕒 Pendiente
- **Objetivo:** Pasar de RegEx $\rightarrow$ NLP Semántico.
- **Técnica:** Implementación de un modelo híbrido (RegEx para velocidad + SLM para complejidad).
- **Meta:** Aumentar la confianza del parseo del 45% al 90% en frases ambiguas.

### Sprint 2: Motor de Decisiones (Financial Intelligence)
- **Estado:** 🕒 Pendiente
- **Objetivo:** Generar "Reglas de Decisión para Mañana".
- **Lógica:** Análisis de runway, detección de cuellos de botella en flujo de caja y priorización de cobros.
- **Meta:** Proporcionar una acción concreta diaria basada en datos.

### Sprint 3: Centro de Control (Visual Analytics)
- **Estado:** 🕒 Pendiente
- **Objetivo:** Visualización avanzada de salud financiera.
- **Componentes:** Dashboard de flujo, mapa de calor de gastos y proyecciones a 30 días.
- **Meta:** Reducir la carga cognitiva del usuario mediante señales visuales claras.

## 🛠️ Stack Técnico Actual
- **Frontend:** React 18, Vite, TypeScript.
- **Backend/DB:** Supabase (Local-first sync).
- **Styling:** CSS custom.
- **PWA:** `vite-plugin-pwa`.
